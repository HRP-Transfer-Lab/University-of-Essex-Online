# Seminar-Led Reading and Assessment Integration — Introduction to Cognitive Psychology

## Design principle

This module is already strongly experiential. Students complete cognitive tasks, work with class data, undertake a formative literature review and write a Scientific Report.

Accordingly, seminars should use **fewer, more purposeful readings** rather than adding a new reading simply because a seminar exists.

The preferred sequence is:

**task / experiment → key reading → interpretation → assessment**

The module's existing reading list is normally sufficient. Additional external readings should be introduced only where they materially improve students' ability to complete an assessment.

# Seminar 1 — Ethics in Cognitive Psychology

## Main function

Module orientation, ethical research practice and preparation for later experimental/report work.

## Core source

### British Psychological Society — *Code of Ethics and Conduct*

Use the four principles already foregrounded in the seminar:

- Respect
- Competence
- Responsibility
- Integrity

## Optional cognitive anchor

### Snyder, Miyake, & Hankin (2015)

Useful only if the seminar needs a concrete example of how cognitive constructs and clinical questions can be linked.

## Assessment connection

This seminar primarily supports:

- Scientific Report C1.4 — broader context and ethics;
- Scientific Report C5 — scientific-report conventions;
- ethical reasoning across later experimental tasks.

No extra reading is necessary for the AI discussion unless University AI guidance is being taught directly.

# Seminar 2 — Change Blindness Cognitive Task

## Main function

Direct preparation for the Units 3–4 CLQ.

## Core reading

### Rensink, O'Regan, & Clark (1997). *To see or not to see: The need for attention to perceive changes in scenes.*

This is the strongest direct anchor because it provides empirical evidence for the phenomenon students have experienced.

## Supplementary readings

### Posner (2012). *Attentional networks and consciousness.*

Useful for attention/awareness.

### Katsuki & Constantinidis (2014). *Bottom-up and top-down attention.*

Useful for moving beyond a simple “not paying attention” explanation and for Unit 3 integration.

### Milner & Goodale — *The Visual Brain in Action*

Use selectively when students need a cognitive-neuropsychological perspective.

## Seminar activity principle

Work from the supplied class task results:

- control RT = 3.65 s;
- full-scene RT = 15.68 s;
- difference p < .001.

Ask students to distinguish:

1. **what the task showed**;
2. **what might explain it**;
3. **what each cognitive approach adds**;
4. **what the result does not prove**.

## Assessment connection

Directly supports all four CLQ criteria, particularly C1.1–C1.4 and C2.1–C2.4.

# Seminar 4 — Writing a Research Report

## Main function

Turn the experiment, literature review and supplied results into a complete scientific report.

## Reading strategy

No new core reading is necessary. Use:

- the **Quantitative Report Template**;
- the **ICP Mock-up Research Report**;
- the student's experiment-specific literature;
- the supplied class results.

## Key seminar emphasis

Students should practise:

- turning literature into a testable hypothesis;
- aligning hypothesis, IV/DV and design;
- distinguishing Results from Discussion;
- comparing class results with prior evidence;
- writing a meaningful limitation rather than a generic weakness.

## Assessment connection

Directly supports Scientific Report C1–C5.

---

# Seminar 5 — Finalising Research Reports & Applications

## Main function

Final Discussion-section support and applied/translational thinking.

## Core source strategy

Use the student's own experiment literature as the main evidence base.

### Optional module anchor

Voss et al. (2017) may be useful for translational/neuroplasticity examples where relevant, but it should **not** be forced into either experiment report.

## Key seminar emphasis

Ask:

- What did the class data actually show?
- How does that compare with previous research?
- What is the strongest warranted real-world implication?
- What limitation most affects interpretation?
- What future study would directly address that limitation?

## Assessment connection

Particularly supports:

- C2.2–C2.4;
- C3.2–C3.4;
- C5.3.

# Reading-engagement expectation

## CLQ

Strong work should normally make substantive use of:

- Rensink et al. (1997);
- at least one relevant attention/approach source such as Posner (2012), Katsuki & Constantinidis (2014), or Milner & Goodale;
- suitable additional evidence where needed.

## Scientific Report

Strong work should normally combine:

- experiment-specific seminal research;
- recent/relevant independently sourced literature;
- literature that helps explain the class result, including null or unexpected findings;
- methodological evidence where needed to support critical evaluation.

The goal is not citation accumulation. The question is whether the reading **does analytical work** in the student's argument.
