# Assessments and Seminars Guidance

This folder contains assessment-specific marking guidance and seminar-reading integration for the Biological Psychology module.

The official University of Essex Online assessment briefs and grading rubrics remain authoritative. The files here operationalise those sources for consistent seminar preparation, assessment support, and later cohort marking.

## Files

- `Seminar_Led_Reading_Integration.md` — core and supplementary readings for Seminars 1–5, using the actual delivery sequence in Units 1, 3, 5, 7 and 9.
- `CLQ_Criteria_and_Subcriteria.md` — four diagnostic subcriteria beneath each official CLQ criterion.
- `Narrative_Review_Criteria_and_Subcriteria.md` — four diagnostic subcriteria beneath each official final-assessment criterion.
- `CLQ_Grading_Specification.md` — operational cohort-marking specification for the CLQ.
- `Narrative_Review_Grading_Specification.md` — operational cohort-marking specification for the final narrative review.

## Delivery map

| Seminar | Delivered in | Main function |
|---|---:|---|
| Seminar 1 | Unit 1 | Module orientation + early CLQ preparation |
| Seminar 2 | Unit 3 | CLQ methods/inference support |
| Seminar 3 | Unit 5 | Introduction to narrative review thinking + memory example |
| Seminar 4 | Unit 7 | Literature-search formative + language/evidence synthesis |
| Seminar 5 | Unit 9 | Final review synthesis + competing biological explanations |

## Diagnostic scoring convention

For later marking, each subcriterion will be rated:

- **1** = fully and convincingly satisfied
- **0.5** = partially, unevenly or ambiguously satisfied
- **0** = absent, seriously incorrect or not meaningfully demonstrated

These values are diagnostic only and do not replace the official weighted rubric.
